## ПРИНЦИП РАБОТЫ:
# 1. Сервер:
  Читает порт из settings.txt (по умолчанию 12345)
  Создает ServerSocket и ждет подключений
  Для каждого клиента создает отдельный поток (ClientHandler)
  Рассылает сообщения всем подключенным клиентам
  Логирует все события в server.log
# 2. Клиент:
  Читает настройки из settings.txt
  Запрашивает имя пользователя
  Подключается к серверу
  Запускает отдельный поток для получения сообщений
  Логирует все отправленные/полученные сообщения в client_username.log
# 3. Протокол обмена:
  Первое сообщение от клиента - имя пользователя
  Последующие сообщения - текст чата
  Команда /exit - отключение от сервера
